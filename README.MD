## Sobre o projeto

Este projeto consiste no desenvolvimento de uma calculadora com interface gráfica utilizando a linguagem Python e a biblioteca Tkinter.

A calculadora permite realizar operações matemáticas básicas de maneira simples e prática, por meio de botões que facilitam a interação com o usuário.

O projeto foi desenvolvido como atividade da disciplina de Desenvolvimento de Sistemas, com o objetivo de praticar conceitos de programação, criação de funções, estruturas condicionais e desenvolvimento de interfaces gráficas.

## Funcionalidades

- Adição (+)
- Subtração (-)
- Multiplicação (X)
- Divisão (÷)
- Utilização de números decimais.
- Botão para limpar todos os valores (C).
- Botão para apagar o último dígito.
- Tratamento de erros, incluindo divisão por zero.

## Tecnologias utilizadas

- Python
- Tkinter (biblioteca para criação de interfaces gráficas).
